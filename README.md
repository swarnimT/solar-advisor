# ☀️ Solar Advisor

Solar Advisor is a solar energy assessment and recommendation platform designed to help users understand what type and size of solar system may suit their electricity consumption, property, backup requirements, and budget.

The application collects user requirements and generates a preliminary solar recommendation including system capacity, panel count, inverter sizing, battery requirements, estimated installation cost, annual savings, and payback period.

## 🚀 Features

- 📍 Location-based user assessment
- ⚡ Electricity consumption analysis
- 🔌 Appliance-based consumption estimation
- 🎯 Solar system requirement assessment
- 🏠 Roof and installation-area assessment
- ☀️ Solar panel sizing
- 🔢 Panel quantity estimation
- ⚡ Inverter sizing
- 🔋 Battery backup estimation
- 💰 Preliminary system cost estimation
- 📈 Estimated annual electricity savings
- ⏱️ Estimated payback period
- 📋 Customer assessment summary
- 📞 Contact information
- ⚠️ Professional planning disclaimer

## 🛠️ Technology Stack

- Python
- Streamlit

## 📊 How It Works

The application follows a step-by-step assessment process:

1. User enters their location.
2. User provides electricity consumption or appliance information.
3. User specifies their solar objectives and backup requirements.
4. User provides roof and installation information.
5. User selects their budget and panel preference.
6. Solar Advisor processes the information.
7. The application generates a preliminary solar system recommendation.
